# Privacy Policy: T&C Summarizer (template: edit and host publicly)

**What we process:** When you click "Summarize this page", the visible text of the current tab is sent to our server, which forwards it to Google's Gemini API to generate a summary. Your IP address and a random anonymous install ID are used only for rate limiting and are retained for up to 48 hours.

**What we don't do:** We don't store page text or summaries, sell data, run ads, or track your browsing. The extension reads a page only when you click the button.

**Third parties:** Google (Gemini API) processes the page text to produce the summary, subject to Google's API terms.

**Local storage:** The extension stores an anonymous install ID and your consent choice in your browser.
